# Source snapshots

Five source documents were imported from ArchStudio on 2026-10-29. `manifest.json` records their original repository-relative paths, base Git commit, working-tree state and SHA-256 of the exact imported bytes.

The two full standard drafts supply the 24 chapters and four appendices in each language. Architecture and transport become marked informative companions. Only the future scenarios/findings from the original review are used in the reading path; historical local receipts are retained in the snapshot but are not republished as runtime evidence for this book.

Snapshots preserve original contents and historical links. They are archival provenance, not the standalone book navigation graph and not an automatically synchronized upstream dependency. The maintained manuscript is under `book/*/src`.
