# Mensoria SQL 官方文档

<div class="edition-label">官方文档 · 语言标准草案 0.1.0-draft.1</div>

为限定作用域、受授权控制的多模型数据平台，定义精确而熟悉的 SQL 语言契约。

本书首版将完整草案整理为可检索、可按章节阅读的参考书：24 章规范正文、4 个规范附录、精确语法，以及 28 个带预期结果的符合性案例。语言版本为 **1**，文档编号 **MSQL-SD-001**，修订号 **0.1.0-draft.1**，日期 **2026 年 10 月 29 日**。

可从[阅读指南](reading-guide.md)开始，按具体操作查阅[语句索引](statement-index.md)，或直接使用[规范规则索引](rules-index.md)。[能力索引](feature-index.md)区分必需、可选、暂缓和预留能力。

## 本版的边界

规范章节定义名称、类型、NULL、关系查询、受守卫保护的修改、请求事务、Schema 提案及可观察错误行为，并区分语言契约要求与实现已经取得的资格证据。

**本书是标准草案，不是已发布的 SQL 实现。** 出版本书不会启用任何档位、驱动、原生事务保证或客户验收结论。

中文版与英文版保留一致的规则编号、能力标识、示例和语法。翻译差异以英文原文为核对依据。两份工程参考及资格验证场景在两版中均保留英文，并明确标为说明性材料。

[版本与来源](edition.md)解释导入边界，[原始资料背景](source-context.md)解决历史引用，使阅读不依赖原工作区。
