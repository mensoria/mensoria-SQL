# 23. 符合性证据与发布要求

<a id="n059"></a>

**N059.** 能力资格验证必须冻结源码／构建／编译器／解析器／后端／存储配置、夹具 Schema／策略／数据、能力限制，以及完整的带类型预期／实际结果。负例必须验证在执行前拒绝；故障案例必须保留未知或失败证据。

必需证据包括附录 B 的语义案例及[验收映射](acceptance-scenarios.md)中的 SQL-A01–A16。差分检查仅针对共同 SQL 子集使用固定版本的参考数据库，并先记录有意保留的差异。有 ORDER BY 时比较完整有序序列，否则比较带类型多重集合。必须保留重复项、NULL 标签和精度。浮点／ANN 模式要求声明误差／质量指标，不得静默认为满足精确案例。

<a id="n060"></a>

**N060.** 文档检查、本地解析器／运行时测试、CI、驱动资格验证、真实客户验收及生产资格验证，必须独立记录。本文件、语法、合成案例集或静态链接检查通过的存在，都不能启用任何 SQL 档位。
