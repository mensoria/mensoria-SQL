# Mensoria SQL Documentation

<div class="edition-label">OFFICIAL DOCUMENTATION · DRAFT 0.1.0-draft.1</div>

A precise language contract for familiar SQL over a scoped, authorized, multimodel data platform.

This first book edition brings the complete Mensoria SQL draft into a navigable reference: 24 normative chapters, four normative appendices, an exact grammar and 28 worked conformance cases. The language version is **1**; the document is **MSQL-SD-001**, revision **0.1.0-draft.1**, dated **29 October 2026**.

Start with [the reading guide](reading-guide.md), use the [statement index](statement-index.md) for a particular operation, or inspect the [normative rule index](rules-index.md). The [feature index](feature-index.md) separates required, optional, deferred and reserved capabilities.

## What this edition promises

The normative chapters specify names, types, NULL, relational queries, guarded mutation, request transactions, schema proposals and observable error behavior. They distinguish what a language contract requires from what an implementation has actually qualified.

**This is a draft standard, not a released SQL implementation.** No profile, driver, native transaction guarantee or customer acceptance is enabled by publishing the book.

The Chinese edition mirrors the same rule IDs, feature IDs, examples and grammar. English is the source for resolving translation discrepancies. The two engineering companions and acceptance scenario reference retain their original English text in both editions and are marked informative.

[Edition and provenance](edition.md) explains the import boundary, and [source context](source-context.md) resolves historical references without requiring the original workspace.
